# 第零节晚自习

正式网页版 1.0.0。作者：大阴希声@UglyNakedGuy。

[在线游玩](https://cooldrug1981.github.io/the-zero-period/)

这是一部发生在虚构的 1997 年鹭原厂办中学的原创科幻悬疑图文小说。沈岑以第一人称叙述；人物之间自然使用的“你”保留在对白里。36 章、12 条支线与 6 个结局均可阅读，并可使用浏览器存档、导入导出和阅读回看。

用户于 2026-09-28 明确同意按现有内容和美术范围发布正式版，并取消原定 1,280 画面、360 母图和全稿审定门槛。本版有 346,063 个独立叙事汉字；48 个已验收画面来自 12 张母图，覆盖前两章。其余场景以文字呈现；57 份内容文件仍未经过逐篇统一编辑审定。审计如实保留这些状态，不把缺图算作画面，也不把未审稿标成已审定。

网页由 `node scripts/build.mjs` 生成到 `web/`，GitHub Pages 部署该目录。当前交付仅涉及 HTML 网页；Windows EXE、ZIP 与 Electron 打包测试暂停，现有本地文件保留且不会上传到仓库。构建与单元测试需要 Node.js；本地浏览器验收另需 Playwright Core 与本机 Chrome。

旧的第一章试玩版保留在独立目录，未纳入本仓库。创作与科学边界规则见 `docs/authoring-contract.md`。
